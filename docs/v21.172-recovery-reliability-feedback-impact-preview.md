# PHOENIX v21.172 — Recovery Reliability Feedback Impact Simulation & Baseline Change Preview Governance

## Purpose
Simulate the downstream effect of human-approved recovery reliability feedback before any new baseline version can be proposed or committed.

## Admission
Only v21.171 `approved-feedback` evidence with human approval may enter. Workspace, baseline ID/version/digest lineage remains exact.

## Preview dimensions
The module records current value, bounded adjustment, candidate value and simulated impacts on score, rank, failover tendency and recovery readiness, together with blast radius and residual risk.

## Guardrails
- Candidate value must equal current value plus approved adjustment.
- Absolute adjustment is bounded by `0.05` by default.
- Candidate values stay in `[0,1]`.
- Blast radius and residual risk are bounded and configurable.
- Risk Brain remains authoritative.
- Duplicate source records fail closed.

## Lifecycle
`review-required -> approved-preview`

Any invalid source, lineage issue, arithmetic mismatch, risk-limit breach, missing approval or Risk Brain block fails closed to `blocked`.

## Safety boundary
Simulation/preview only. No baseline, consumer, route, policy, credential, permission, trade, fund or device state is changed.
