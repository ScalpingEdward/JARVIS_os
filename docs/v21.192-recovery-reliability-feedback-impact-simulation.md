# PHOENIX v21.192 — Recovery Reliability Feedback Impact Simulation & Baseline Change Preview Governance

## Purpose
Simulate the bounded effect of approved recovery-reliability feedback before any new baseline proposal can be versioned or committed.

## Admission
Only human-approved v21.191 `approved-feedback` evidence is admitted. Workspace, baseline ID, version and digest remain exact lineage bindings.

## Simulation
The module derives a candidate value from the current baseline value plus the bounded feedback adjustment and records preview metrics for score impact, rank impact, failover tendency, recovery readiness, blast radius and residual risk.

Feedback adjustment is capped at an absolute `0.05`. Candidate values must remain within `[0.0, 1.0]`. Impact metrics are bounded to `[-1.0, 1.0]`. Blast radius and residual risk must remain inside configured governance limits.

## Lifecycle
`review-required -> approved-preview`

Invalid lineage, unsafe limits, duplicate source evidence or Risk Brain hard blocks fail closed to `blocked`.

Final preview approval requires explicit human approval.

## Safety boundary
Simulation/governance only. This module does not mutate a baseline, activate runtime consumers, change routing/policy, expand credentials/permissions, submit trades, move funds or actuate devices.
