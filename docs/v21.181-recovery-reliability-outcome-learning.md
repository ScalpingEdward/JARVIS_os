# PHOENIX v21.181 — Recovery Reliability Outcome Learning & Baseline Feedback Governance

## Purpose
Convert a human-approved closed recovery episode into bounded reliability-learning evidence for later baseline impact simulation.

## Admission
Only a v21.180 source in `closed` state with human approval may enter. Workspace, baseline ID, baseline version and baseline digest remain bound to the learning record.

## Evidence model
The module binds:
- stability score
- aggregate confidence
- recovery quality
- residual risk
- requested bounded baseline adjustment

A deterministic learning score combines these signals. Poor evidence, invalid lineage, duplicate source reuse, Risk Brain hard blocks, invalid normalized values or an absolute requested adjustment above `0.05` fail closed to `blocked`.

## Lifecycle
`review-required -> approved-feedback`

Final feedback eligibility requires explicit human approval.

## Safety boundary
This module produces learning evidence only. `approved-feedback` does not mutate or activate a baseline, modify runtime consumers, change routing/policy, expand permissions/credentials, submit trades, move funds or actuate devices.
