# PHOENIX v21.190 — Recovery Reliability Stability Observation & Episode Closure Governance

## Purpose
Observe the post-recovery consumer set after v21.189 completion and close the recovery episode only when stability remains above policy thresholds.

## Admission
Only human-approved v21.189 `completed` evidence is admitted. Workspace and baseline ID/version/digest lineage must remain exact.

## Observation model
Every expected consumer must provide one observation with:
- health state
- dependency satisfaction
- latency quality
- error quality
- confidence
- freshness

The governance service computes a deterministic aggregate stability score and residual-risk score.

## Lifecycle
`review-required -> closed`

Unstable evidence moves to `degraded`. Invalid lineage, incomplete observation sets, duplicate consumers, invalid normalized values or Risk Brain blocks fail closed to `blocked`.

Final closure requires explicit human approval.

## Safety boundary
Observation/governance only. This module does not activate or roll back baselines, mutate consumers, change routing/policy, expand permissions, execute trades, move funds or actuate devices.
