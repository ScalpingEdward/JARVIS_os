# PHOENIX v21.182 — Recovery Reliability Feedback Impact Simulation & Baseline Change Preview Governance

## Purpose
Simulate the downstream impact of human-approved recovery reliability feedback before any versioned baseline proposal is created.

## Admission
Only v21.181 evidence in `approved-feedback` state with human approval is admitted. Workspace, baseline ID/version/digest and source lineage remain bound to the preview.

## Simulation outputs
- current baseline value
- bounded feedback adjustment
- candidate baseline value
- score impact
- rank impact
- failover tendency impact
- recovery readiness impact
- blast radius
- residual risk

## Guardrails
- absolute feedback adjustment <= 0.05
- current/candidate baseline value must remain within 0.0–1.0
- impact metrics are normalized
- blast radius and residual risk are bounded
- Risk Brain hard blocks fail closed
- duplicate source evidence fails closed
- human approval is required before `approved-preview`

## Lifecycle
`review-required -> approved-preview`

Invalid, unsafe, replayed or out-of-bounds evidence transitions to `blocked`.

## Safety boundary
Simulation/governance only. No live/committed baseline, consumer, routing table, policy, credential, permission, execution path or device state is changed by this module.
