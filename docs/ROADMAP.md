# JARVIS OS — Roadmap

## Phase 0 — Foundation
Status: IN PROGRESS

- Master plan
- Architecture baseline
- Agent operating contract
- Security rules
- Definition of Done
- Initial task backlog
- GitHub branch and pull-request workflow

Exit condition: governing documents are reviewed and merged to `main`.

## Phase 1 — Core Platform
- FastAPI service and health endpoint
- Configuration management
- Provider-neutral model interface
- Claude and OpenAI adapters
- Basic model routing policy
- Structured logging
- Automated test pipeline

## Phase 2 — Agent Operations
- Task model and state machine
- Dependency-aware queue
- Master Agent planning interface
- Worker registration and capability profiles
- Progress reports and stop conditions
- GitHub issue/PR integration

## Phase 3 — Safety and Memory
- Risk classification
- Approval requests
- Audit log
- User-controlled long-term memory
- Retrieval and deletion controls
- Backup and restore

## Phase 4 — Control Interface
- Web dashboard
- Mobile-friendly access
- Voice input/output
- Daily work reports
- Cost and token monitoring

## Phase 5 — First Specialist Module
Telegram Signal Center:
- Signal ingestion
- Parser and validation
- Dashboard and database
- No live MT5 execution in the first release

## Later phases
- MT5 bridge with strict risk controls
- Business and e-commerce automation
- Email, calendar, and document tools
- Vision and chart analysis
- Smart-home integrations
- Portable encrypted deployment package
