# PHOENIX v21.171 — Recovery Outcome Reliability Learning & Baseline Feedback Governance

## Purpose
Convert a human-approved closed recovery episode into bounded reliability-learning evidence for later baseline simulation and proposal workflows.

## Admission
Only v21.170 evidence in `closed` state with human approval may enter. Workspace, baseline ID, version and digest remain exact lineage bindings.

## Learning inputs
- stability score
- aggregate confidence
- recovery quality
- residual risk
- previous reliability baseline value

All normalized values must be within 0.0–1.0.

## Output
A deterministic learning score and a proposed reliability value. The proposal is bounded to a maximum absolute adjustment of 0.05 from the previous reliability value.

## Lifecycle
`review-required -> approved-feedback`

Invalid admission, invalid metrics, duplicate source evidence or Risk Brain hard block fails closed to `blocked`.

## Safety boundary
This module produces learning evidence and a proposal only. It does not activate or mutate a baseline, modify consumers, change routing/policy, expand permissions/credentials, move funds, submit orders or actuate devices.
