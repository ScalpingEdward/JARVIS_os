# AURON Mobile Avatar Scope

The mobile client will be a PWA first, installable on Android and iPhone without app-store release.

Planned capabilities:
- animated AURON avatar
- push-to-talk and text chat
- spoken replies
- live activity feed without reading internal traces aloud
- approvals and execution status
- synchronized sessions between desktop, Telegram and mobile web

A native app can follow after the PWA workflow is stable.
